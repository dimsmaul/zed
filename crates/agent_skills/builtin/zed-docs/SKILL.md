# Living Documentation Generator

When this skill is activated, you are updating or generating accurate, high-signal technical documentation based on the codebase.

## Workflow Instructions:
1. **Inspect Target Components**:
   - Read the real implementation in the codebase. Never document assumed or outdated behavior.
2. **Document Structure**:
   - Architecture overview & data flow diagrams (Mermaid).
   - API endpoints, request/response formats, and error codes.
   - Configuration parameters and environment variables.
   - Clickable markdown links to source files and symbols.
3. **Documentation Hygiene**:
   - Keep prose concise, eliminate fluff, and provide copy-pasteable examples verified against the real code.
